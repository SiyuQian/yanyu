# 言语 · Yanyu

[English](README.md) | **简体中文**

言语是基于 [Handy](https://github.com/cjpais/Handy) 的个人语音输入项目。我们计划加入个人语音样本的整理、人工校正和导出，为模型训练积累数据。

应用已使用言语 · Yanyu 品牌和独立标识。桌面工作空间默认以 1120 × 780 打开，提供分组导航、固定页面标题，以及柔和青绿色的浅色和深色主题，同时适配较小窗口。训练数据导出和模型训练流程尚未实现。

可选的本地润色在 Apple Silicon Mac 上使用 Qwen3-0.6B 和固定的保守清理规则，可在常规设置中启用。已启用的个性化资料仅提供术语背景，禁用或删除的资料不影响本地润色。提示词编辑区已移除，但已保存的旧提示词仍保留在磁盘上。本地预览与日常听写使用相同处理，不回退到外部服务。超过 200 字的输入跳过本地润色；模型不可用、输出无效或超过 500 毫秒时保留原始转写。

关闭本地润色时，已启用的个性化会通过配置的服务自动处理每次听写，发送转写和已启用的资料背景，不发送录音。可选录音预览使用相同的清理方式，无需另行激活。服务失败、输出无效或超过 10 秒时保留原始转写。两条路径都检查语言保留、标识符和超出删除范围的改写。这些检查无法保证语义忠实性。

## 选中文字润色

在 Apple Silicon Mac 上，在其他应用中选中消息后，按 **Option + Shift + P** 即可预览本地润色草稿。快捷键可在常规设置中修改。润色会修正语法、拼写和标点，并尽量让语气自然、礼貌，同时保留原意和原语言。模型输出可能改变原意，请检查后使用。只有点击「复制润色结果」才会复制文字，不会替换选中文字或发送消息。按 Escape 可关闭预览并取消正在进行的处理。

请先在「常规 → 共享本地文本模型」手动下载 Qwen3-0.6B。选中文字润色独立于听写润色开关，最多接受 10,000 字，不会将选中文字发送到外部服务或存入历史记录。不通过 macOS 辅助功能接口提供选中文字的应用暂不支持。模型缺失、输出不完整或超时时会显示错误，原文和剪贴板保持不变。

## 本地会议纪要

「会议」页面在运行 macOS 13 或更高版本的 Apple 芯片 Mac 上支持现场会议麦克风录音，以及线上会议的麦克风与电脑音频录音。暂停时间不计入录音时间。两种音源分别增量写入本地磁盘；中断后仅恢复已经提交的音频。录音、带时间戳的转写、发言人显示名称和可编辑纪要独立于听写历史保存，直至手动删除。支持回放、文字校正、发言人重命名和 Markdown 导出。

处理前，请明确在「模型」中安装 MOSS-Transcribe-Diarize，并在「通用 → 本地润色」下载现有 Qwen3-0.6B 文件。会议处理不会更改听写模型，也不要求开启听写润色。录音结束后在本地处理，支持重试和取消。纪要使用已验证的转写原文作为依据，而非生成事实性改写；自动纪要是需要逐条核对来源的草稿：真实 Qwen 测试已出现任务遗漏和错误分类。模型缺失、无效或输出不完整会明确报错，不会自动下载或回退到云端。

跨窗口发言人匹配使用声学参考音频，并标记不确定的归属。真实 MOSS 中英混合语音的发言人质量、原生权限与设备行为、听写静音设置下的并行录音，以及两小时有声会议推理尚未验证；合成存储测试不代表这些条件已通过。可按[会议验证说明](docs/DEVELOPMENT.md#meeting-notetaker-verification)运行本地实验。Windows、Linux 和 Intel Mac 不支持会议录音，现有听写功能继续保留。

## 技术栈与开发

- 界面：React、TypeScript、Tailwind CSS
- 桌面应用：Tauri 2、Rust
- 语音识别：本地模型推理

开发环境需要 Bun、Rust 和对应平台的 Tauri 构建依赖。完整步骤见 [BUILD.md](BUILD.md)。

```bash
bun install
bun run tauri dev
```

项目导航见 [AGENTS.md](AGENTS.md)，架构说明见 [ARCHITECTURE.md](ARCHITECTURE.md)，完整开发参考见 [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)。首次开发需按开发参考准备 Silero VAD 模型。个人录音和训练数据应保存在本地，不要提交到这个公开仓库。
