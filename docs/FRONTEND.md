# Frontend

[App.tsx](../src/App.tsx) owns onboarding, permissions, section selection and the settings shell. [Sidebar](../src/components/Sidebar.tsx) maps sections to components. The overlay has a separate [entry directory](../src/overlay/).

Use functional React components and hooks. [useSettings](../src/hooks/useSettings.ts), [settings store](../src/stores/settingsStore.ts), and [model store](../src/stores/modelStore.ts) connect UI state to Tauri. [Bindings](../src/bindings.ts) are generated by debug Rust startup registration, not an independent handwritten contract.

Strict TypeScript and the `@/` alias are defined in [tsconfig](../tsconfig.json). Styling uses Tailwind and shared CSS. Reuse [UI components](../src/components/ui/) and [shared components](../src/components/shared/).

All user-facing UI text uses i18next. Add keys to [English translations](../src/i18n/locales/en/translation.json), then follow [translation contribution instructions](../CONTRIBUTING_TRANSLATIONS.md). ESLint checks JSX content only and ignores some attributes; review other user-facing strings.

## Checks

- `bun run build`: TypeScript and production Vite bundle.
- `bun run lint`: JSX translation literal rule.
- `bun run check:translations`: locale consistency.
- `bun run test:keyboard`: keyboard utilities.
- `bun run test:playwright`: Chromium UI tests with the Vite server from [Playwright configuration](../playwright.config.ts).

Browser coverage does not substitute for desktop microphone, global shortcut, accessibility or OS paste checks.
